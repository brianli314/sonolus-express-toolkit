# Sonolus Express Toolkit
Python toolkit for setting up a server using [Sonolus Express](https://github.com/Sonolus/sonolus-express). Includes importing and configuring levels, and engine setup with various methods.

# Documentation

- [Repository and server](repository-and-server.md): architecture, catalogue
  layout, generated files, TypeScript, and Caddy.
- [Import workflows](import-workflows.md): setup, every importer command,
  ChartDownloader, converters, and generated backgrounds.

Background notes are included in the import guide because background generation
is part of level importing rather than a separate workflow.
